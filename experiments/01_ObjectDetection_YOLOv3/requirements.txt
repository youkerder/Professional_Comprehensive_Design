# 实验 01 · 目标检测（keras-yolo3 / YOLOv3）依赖
#
# 环境：Python 3.10（本机实际使用）
# ---------------------------------------------------------------------------
# 与指导书的差异（详见 ../README.md 第三节与实验报告 2.4 节）
#
# 指导书环境一是 python 3.7/3.8 + tensorflow 2.3.0 + keras 2.4.3，
# 但在本机上装不起来：venv 里 Python 3.8 的 OpenSSL 1.1.1 访问 pypi 时
# 间歇性 TLS 握手失败（SSLError 142, ASN1: NOT_ENOUGH_DATA）；
# 同一批 URL 用 Python 3.10 / 3.12 访问正常，换明文 HTTP 源也会被重定向到 443。
#
# 因此改用 Python 3.10 + tensorflow 2.10.0。选 2.10 而不是更新的版本，
# 是因为它仍属于 **Keras 2**（keras.backend / fit_generator /
# Lambda(arguments=...) 都还在），keras-yolo3 的改动最小。
#
# 本机 TF 只能 CPU：RTX 4060 是 sm_89（Ada），需要 CUDA 11.8+；
# 而 tensorflow 2.10.0 绑定 CUDA 11.2（最高 sm_86），
# TensorFlow 自 2.11 起取消 Windows 原生 GPU 支持。
# ---------------------------------------------------------------------------
#
# 建议直接用脚本建环境（会自动建 venv 并安装下面这些）：
#     python envs/setup_tf_env.py
#
# 手动安装时注意：一定要加 --only-binary=:all:，
# 否则 pip 的解析器会在大量源码包候选上反复回溯、长时间无响应。
# ---------------------------------------------------------------------------
